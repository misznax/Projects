# Ilustracje — tanie rozwiązania (decyzja: nie zastanawiać się ponownie)

Canva MCP: limit kredytów, miniatury ~199×150 → NIE używać do seryjnych grafik. Pinterest: brak API.

Kolejność działania (bez kredytów, w chmurze):
1. **Everkinetic** (CC BY-SA 4.0, github.com/everkinetic/data) — >300 rysunków SVG, pary start/koniec. Dobierać do ćwiczeń ruchowych (brzuch, plecy, rozciąganie) jak w Ruchu (`EKIMG`, pliki `public/ek-ID-a/b.svg`).
2. **Ruch** — para a/b animowana CSS (płynne przenikanie start↔koniec, ~1,6 s w pętli) zamiast dwóch obrazków obok siebie; `prefers-reduced-motion` = statyczne.
3. **Otwarte ilustracje** (unDraw, Open Peeps, SVG Repo, Wikimedia Commons) — tylko dla oddechu/uwagi (pozycja siedząca, dłoń na brzuchu); sprawdzać licencję i dopisać w „O autorze”.
4. **Oznaczenia kroków** (strzałki wdech/wydech/zatrzymaj) jako CSS/SVG, bez grafik.
5. Grafiki „realistyczne ruchome” (wideo AI) — tylko jeśli darmowe/tanie; inaczej pomijać.

Odrzucone: grafika „brzuch” z Canvy (wyglądała jak ciąża); własne SVG-figurki (słaba jakość).
