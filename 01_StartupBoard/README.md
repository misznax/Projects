# Startup Board

6–8 swobodnych paneli roboczych (pliki tekstowe z kolorowaniem Python/HTML/SQL, PDF) z pamięcią stanu.
Autor: Michał Rzekiecki · kontakt: michus@gmail.com

- Pobierz: Releases → `startupboard-latest` → `StartupBoard.zip`, rozpakuj i uruchom `StartupBoard.exe`.
- Źródła: `src/`, build: `python build_exe.py`, kopie wersji: `backup/`.
- Stan zapisuje się w `%LOCALAPPDATA%\smialo\StartupBoard\` (menu Pomoc → „Folder z ustawieniami").
